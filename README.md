# Suds & Sunshine

A cozy 3D laundry game made with Three.js and custom cloth physics.

Pull clothes from the basket, scrub out the stains, rinse, wring, hang them to dry, then fold and stack them for coins. Spend the coins on upgrades in the shop.

**Play:** https://kormocicsaba.github.io/suds-and-sunshine/

Run it locally with `python serve.py 5173`, then open http://localhost:5173.
